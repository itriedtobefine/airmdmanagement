# Добавлены функции AirTable в прототип редактора таблиц

## Новые возможности

### 1. Расширенные типы полей (Rich Field Types)
- **Single Select** - выбор одного значения из списка
- **Multi Select** - выбор нескольких значений (JSONB)
- **Checkbox** - булевы значения
- **Date/DateTime** - даты и время
- **Email, URL, Phone** - специализированные текстовые поля
- **Currency, Percent** - числовые форматы
- **Rating** - рейтинговые поля
- **Long Text** - многострочный текст
- **Attachment** - вложения (JSONB)

### 2. Связи между таблицами (Relationships)
- **Link to Record** - связь с другой таблицей через foreign key
- Автоматическое создание FK constraints
- Получение связанных записей

### 3. Формулы (Formula Fields)
- Вычисление значений на основе других полей
- Поддержка функций: len, sum, min, max, abs, round
- Работа с датами: today, now
- Безопасное выполнение выражений

### 4. Представления данных (Views)
- **Grid View** - табличный вид с инлайн-редактированием
- **Kanban View** - группировка по колонкам
- **Gallery View** - карточки с изображениями
- Сохранение конфигурации представлений в БД
- Фильтры, сортировки для каждого представления

### 5. История изменений и Undo/Redo
- Полная история всех изменений (создание, обновление, удаление)
- Отмена последней операции
- Хранение старых и новых значений
- Информация о пользователе и времени изменения

### 6. Комментарии к записям
- Добавление комментариев к любой записи
- Просмотр истории комментариев
- Панель комментариев с боковой стороны
- Привязка к конкретным записям

### 7. Массовые операции (Bulk Operations)
- Выделение нескольких записей
- Массовое удаление выбранных записей
- Пакетное обновление

### 8. Поиск и фильтрация
- Полнотекстовый поиск по всем текстовым полям
- Фильтрация по операторам: equals, contains, greater_than, less_than
- Проверка на пустые/непустые значения
- Группировка результатов

### 9. Экспорт/Импорт данных
- Экспорт таблиц в CSV формат
- Импорт данных из CSV файлов
- Правильная обработка специальных символов

### 10. Метаданные записей
- Автоматическое отслеживание created_at, updated_at
- Версионирование записей (_version)
- Отслеживание создателя (_created_by, _updated_by)

### 11. Валидация полей
- Required поля
- Значения по умолчанию
- Мин/макс значения для чисел
- Regex паттерны для текста

## Технические улучшения

### Backend
- Enum для типов полей (FieldType)
- Enum для операторов фильтрации (Operator)
- Dataclass для конфигурации полей (FieldConfig)
- Dataclass для представлений (ViewConfig)
- Dataclass для комментариев (Comment)
- Dataclass для истории изменений (ChangeRecord)
- Менеджер метаданных (MetadataManager)
- Таблицы для хранения views, comments, history

### Frontend
- Переключение между Grid/Kanban/Gallery видами
- Боковая панель комментариев
- Модальные окна для создания таблиц/представлений
- Inline-редактирование ячеек
- Чекбоксы для массового выбора
- Пагинация с навигацией
- Toast-уведомления об операциях
- Индикатор загрузки

### API Endpoints
```
GET    /api/tables                          - список таблиц
GET    /api/tables/{name}/schema           - схема таблицы
GET    /api/tables/{name}/data             - данные с пагинацией
POST   /api/tables/{name}/records          - создание записи
PUT    /api/tables/{name}/records/{id}     - обновление записи
DELETE /api/tables/{name}/records/{id}     - удаление записи
POST   /api/tables/{name}/bulk-delete      - массовое удаление
POST   /api/tables                         - создание таблицы
DELETE /api/tables/{name}                  - удаление таблицы
POST   /api/tables/{name}/columns          - добавление колонки
DELETE /api/tables/{name}/columns/{name}   - удаление колонки
GET    /api/tables/{name}/export/csv       - экспорт в CSV
POST   /api/tables/{name}/import/csv       - импорт из CSV
GET    /api/views                           - список представлений
POST   /api/views                           - создание представления
DELETE /api/views/{id}                      - удаление представления
GET    /api/comments/{table}/{record}      - комментарии записи
POST   /api/comments                        - добавление комментария
GET    /api/history                         - история изменений
POST   /api/undo                            - отмена операции
```

## Сравнение с базовым прототипом

| Функция | Было | Стало |
|---------|------|-------|
| Типы полей | text, number | 20+ типов |
| Представления | только grid | grid, kanban, gallery |
| Связи таблиц | нет | foreign keys |
| Формулы | нет | есть |
| История | нет | полная + undo |
| Комментарии | нет | есть |
| Массовые операции | нет | есть |
| Поиск | нет | полнотекстовый |
| Экспорт/Импорт | нет | CSV |
| Метаданные | нет | versioning, timestamps |
