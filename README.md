# Система оценки стоимости разработки справочников

Веб-приложение для оценки экономической эффективности передачи разработки и поддержки справочников другой команде.

## Возможности

- **NLP-анализ** текстового описания справочника/реестра
- **Автоматический расчет** стоимости разработки и годовой поддержки
- **Детализация расходов** по компонентам и специалистам
- **Валидация запросов** - отклоняет запросы вне сферы RDM/MDM
- **Минималистичный веб-интерфейс** на чистом JS

## Структура проекта

```
/workspace
├── main.py                 # FastAPI приложение
├── download_model.py       # NLP-модуль (извлечение параметров из текста)
├── calculator.py           # Расчетный движок
├── data/
│   ├── development_norms.csv  # Нормативы времени на разработку
│   ├── support_norms.csv      # Нормативы времени на поддержку

├── templates/
│   └── index.html        # Веб-интерфейс
├── models/               # Кэш NLP-модели (создается автоматически)
└── README.md             # Этот файл
```

## Запуск приложения

### Вариант 1: Прямой запуск через uvicorn

```bash
cd /workspace
uvicorn main:app --host 0.0.0.0 --port 8000
```

### Вариант 2: Через Python

```bash
cd /workspace
python main.py
```

Приложение будет доступно по адресу: http://localhost:8000

## Использование

1. Откройте веб-интерфейс в браузере
2. Введите описание планируемого справочника или реестра
3. (Опционально) Укажите часы на поддержку в месяц, если известно
4. Нажмите "Рассчитать стоимость"
5. Получите результат с детализацией

### Примеры запросов

✅ **Корректные запросы:**
- "Разработка справочника ОКАТО с интеграцией получения данных из внешнего источника"
- "Ручной справочник с типовыми правилами валидации"
- "Реестр классификации данных со сложными правилами валидации"
- "MDM решение с мастерингом данных и дедупликацией"
- "НСИ с иерархией и версионированием"

❌ **Запросы будут отклонены:**
- "Создание интернет-магазина"
- "Разработка социальной сети"
- "Мобильное приложение для доставки"

## API Endpoints

### POST /api/estimate
Оценить стоимость разработки и поддержки.

**Request:**
```json
{
    "description": "Разработка справочника с интеграцией",
    "custom_support_hours": 10
}
```

**Response:**
```json
{
    "success": true,
    "development_cost": 163700,
    "support_cost_yearly": 72000,
    "total_first_year": 235700,
    "development_breakdown": {...},
    "support_breakdown": {...},
    "summary": "...",
    "detected_tasks": ["external_integration", ...],
    "tech_stack": []
}
```

### GET /api/norms/development
Получить нормативы на разработку.

### GET /api/norms/support
Получить нормативы на поддержку.

### GET /api/rates
Получить часовые ставки.

## Настройка нормативов

Вы можете изменить нормативы времени и ставки в CSV-файлах:

- `data/development_norms.csv` - время на разработку (часы)
- `data/support_norms.csv` - время на поддержку (часы/месяц)
- `data/hourly_rates.csv` - ставки специалистов (руб/час)

## Локальная работа

Приложение работает полностью локально:
- NLP-модуль использует правила и ключевые слова (не требует внешних API)
- Все данные хранятся в CSV-файлах
- Не требуется GPU или облачные сервисы
