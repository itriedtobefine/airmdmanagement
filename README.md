# Task Decomposition Application

Приложение для декомпозиции задач на подзадачи с использованием локальной ИИ-модели.

## Описание

Программа принимает текстовый запрос (задачу) и использует локальную LLM-модель для декомпозиции этой задачи на подзадачи. Результат возвращается в структурированном формате JSON.

## Требования

- Python 3.8+
- llama-cpp-python==0.2.60
- Свободное место на диске: ~700 МБ (для модели TinyLlama-1.1B)

## Установка

### 1. Установка зависимостей

```bash
pip install llama-cpp-python==0.2.60 --prefer-binary --only-binary :all: --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu/
```

### 2. Очистка кеша pip (рекомендуется для экономии места)

```bash
pip cache purge
```

### 3. Скачивание модели

Модель можно скачать автоматически при первом запуске с флагом `--download` или вручную:

```bash
# Автоматическая загрузка при запуске
python task_decomposer.py "Разработай интернет-магазин" --download

# Или вручную
mkdir -p models
wget https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF/resolve/main/tinyllama-1.1b-chat-v1.0.Q2_K.gguf -O models/tinyllama-1.1b-chat-v1.0.Q2_K.gguf
```

**Примечание:** Размер модели составляет около 400 МБ (Q2_K квантование). Убедитесь, что у вас достаточно свободного места на диске (рекомендуется минимум 450 МБ).

## Использование

### Базовое использование

```bash
python task_decomposer.py "Разработай интернет-магазин"
```

### С указанием пути к модели

```bash
python task_decomposer.py "Ваша задача" --model /path/to/model.gguf
```

### С автоматической загрузкой модели

```bash
python task_decomposer.py "Ваша задача" --download
```

### Через stdin

```bash
echo "Разработай мобильное приложение" | python task_decomposer.py
```

### Интерактивный режим

```bash
python task_decomposer.py
# Введите задачу когда появится приглашение
```

## Параметры командной строки

| Параметр | Краткий | Описание |
|----------|---------|----------|
| `task` | - | Текст задачи для декомпозиции |
| `--model` | `-m` | Путь к GGUF модели (по умолчанию: `models/tinyllama-1.1b-chat-v1.0.Q2_K.gguf`) |
| `--download` | `-d` | Автоматически скачать модель если она отсутствует |
| `--model-url` | `-u` | URL для скачивания модели |
| `--max-subtasks` | `-n` | Максимальное количество подзадач (по умолчанию: 10) |

## Формат вывода

Программа возвращает JSON следующего формата:

```json
{
  "original_task": "Разработай интернет-магазин",
  "subtasks": [
    {
      "id": 1,
      "title": "Определение требований",
      "description": "Формализация бизнес-требований, пользовательских сценариев...",
      "priority": "high"
    },
    {
      "id": 2,
      "title": "Выбор архитектуры",
      "description": "Проектирование системной архитектуры...",
      "priority": "high"
    }
  ]
}
```

### Поля subtasks

- `id` - Уникальный идентификатор подзадачи
- `title` - Краткое название подзадачи
- `description` - Подробное описание подзадачи
- `priority` - Приоритет: `high`, `medium`, или `low`

## Примечания

1. **Требования к диску**: Модель TinyLlama-1.1B занимает около 637 МБ. Приложение проверяет свободное место перед загрузкой и оставляет 10% буфер.

2. **Производительность**: Время обработки зависит от размера задачи и доступных ресурсов. На CPU обработка может занять несколько секунд.

3. **Качество результатов**: TinyLlama-1.1B - компактная модель. Для более сложных задач рекомендуется использовать модели большего размера (при наличии достаточного места на диске).
