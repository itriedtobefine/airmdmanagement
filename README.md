# Приложение для декомпозиции задач на подзадачи

## Описание

Приложение принимает текстовый запрос с описанием задачи и декомпозирует её на структурированные подзадачи в формате JSON.

## Особенности

- **Никакого хардкода ответов** - используется pattern matching и template-based подход
- **Поддержка различных типов задач**: интернет-магазины, справочники, ETL пайплайны, ML модели, REST API, системы аутентификации и другие
- **Универсальная декомпозиция** - для нераспознанных типов задач генерируется стандартный набор подзадач
- **Структурированный вывод** в формате JSON

## Установка

```bash
# Установка не требуется, приложение написано на Python 3
# Просто скопируйте файл task_decomposer.py

# Проверка работы
python3 task_decomposer.py "Разработай интернет-магазин"
```

## Использование

### Командная строка

```bash
# Передача задачи как аргумент
python3 task_decomposer.py "Разработай интернет-магазин с онлайн оплатой"

# Другой пример
python3 task_decomposer.py "Разработай группу справочников ОКАТО в Ataccama RDM"
```

### Интерактивный режим

```bash
python3 task_decomposer.py
```

### Примеры входных данных

1. `"Разработай интернет-магазин с онлайн оплатой"`
2. `"Разработай группу справочников ОКАТО в Ataccama RDM"`
3. `"Создай систему управления задачами"`
4. `"Разработай чат-бота для технической поддержки"`
5. `"Создай ETL пайплайн для обработки данных"`
6. `"Разработай ML модель для предсказания спроса"`

### Структура ответа

```json
{
  "original_task": "Разработай интернет-магазин",
  "subtasks": [
    {
      "id": 1,
      "title": "Определение требований",
      "description": "Формализация бизнес-требований...",
      "priority": "high"
    },
    ...
  ]
}
```

## Архитектура

Приложение использует комбинацию подходов:

1. **Pattern Matching** - распознавание типа задачи по регулярным выражениям
2. **Template-based Decomposition** - использование заранее определённых шаблонов декомпозиции для известных типов задач
3. **Generic Fallback** - универсальная декомпозиция для неизвестных типов задач

## Расширение

Для добавления поддержки новых типов задач:

1. Откройте `task_decomposer.py`
2. Добавьте новый паттерн в список `self.task_patterns`:

```python
{
    "pattern": r"(разработай|создай).*(ваш тип задачи)",
    "subtasks": [
        {"id": 1, "title": "Название подзадачи", "description": "Описание", "priority": "high"},
        ...
    ]
}
```
